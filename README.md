# 📌 Project Overview

This project simulates a real-world E-Commerce database using PostgreSQL.

The main objective is to practice SQL for Data Analytics by solving real business problems using a relational database.

This project covers everything from database design to advanced SQL analytics.

---

# 🎯 Objectives

- Design a normalized relational database
- Populate the database with realistic data
- Solve business problems using SQL
- Practice PostgreSQL features
- Build a portfolio-ready project

---

# 🗂 Database Schema

The project contains the following tables:

- Customers
- Categories
- Products
- Orders
- Order Items
- Payments
- Shipping
- Returns

Then execute the queries from the **queries** folder.
